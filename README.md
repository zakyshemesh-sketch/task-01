# תעודת זהות משבשת

**משימה 1** · קורס עיצוב בעזרת בינה מלאכותית, M.Des, HIT 2026 · דפני פרלמן ואיתן ברטל

צחי שמש

## הרעיון

ביקשתי ממודל לתאר אותי, בטקסט ובתמונות. הוא החזיר את הממוצע: גבר עם זקן אפור ובלייזר, סלון של מגזין, ילדות עם כביסה תלויה. נכון בערך, חלק, משכנע, ולא אני.

העמוד הוא מסע גלילה. מלמעלה, השכבה של המכונה: הביוגרפיה והתמונות שהמודל ייצר. תוך כדי גלילה היא נקרעת, ומתחתיה מתגלה קולאז' של מה שהמודל לא יכול היה לדעת: התמונות האמיתיות, כתב היד, הרחוב, המשפטים של המשפחה.

| שכבה | מה זה | של מי |
|---|---|---|
| **טופסולוגיה** | הטקסט והתמונות שהמודל ייצר עליי. זה מה שנקרע | של המכונה |
| **סדר** | גריד מודרניסטי, מצויר ביד בעיפרון | שלי |
| **שבירה** | קולאז', קריעות אמיתיות, אותיות גזורות, צבע ריזו | שלי |

המילה שמחזיקה את העבודה היא **חיכוך**: המודל נותן את הממוצע מיד, והאמת דורשת מאמץ.
